# One Guide Advisors

Website for One Guide, a UK higher education consultancy helping students secure university places and Student Finance England funding.

Built as a single-page PHP application with multilingual support (English, Romanian, Polish, Hungarian, Spanish, Italian, Portuguese, Greek, Bulgarian), a course search tool, team profiles, a review system, and an AI chatbot.

**Stack:** PHP, Tailwind CSS, JavaScript, Google Gemini API

## Setup

Clone the repo, copy `config.example.json` to `config.json`, and fill in your API keys.

```bash
cp config.example.json config.json
```

Needs a PHP server to run (Apache/Nginx or `php -S localhost:8000`).
